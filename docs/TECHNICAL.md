# Разработка DevNotes

## Требования

macOS 14+, инструменты разработчика Apple со Swift 6.0+ и SDK macOS.
Проект собирается через Swift Package Manager в режиме языка Swift 5,
без сторонних Swift-зависимостей.

Команды ниже выполняются из корня репозитория.

## Сборка приложения

```sh
zsh scripts/build-app.sh
open dist/DevNotes.app
```

Скрипт использует SDK выбранных инструментов разработчика и создаёт приложение
для текущей архитектуры. Результаты сборки и кеши исключены из Git.

## Проверки

```sh
zsh scripts/check.sh
```

Пять наборов проверок покрывают чтение и сохранение архива, режимы входа,
привязки редактора, накопление диктовки и экспорт таблиц.
Они используют временные синтетические данные и имитацию аутентификации;
личные заметки, микрофон и значения ключей не читаются.
Это отдельные Swift-программы в `Checks/`, а не target для `swift test`.

## Установщик

```sh
zsh scripts/package-release.sh
```

Дополнительно нужны Python 3 с pip и `rg` (ripgrep).
Скрипт устанавливает закреплённые версии `ds-store` и `mac-alias`
в `.build/dmg-tools`. Версия приложения берётся из `Info.plist`.

Universal-сборка для Apple Silicon и Intel, DMG, ZIP, инструкция и SHA-256
появляются в `releases/DevNotes-<версия>-installer/`.
Существующий релиз не перезаписывается. Временные копии удаляются после упаковки.
Скрипт проверяет подпись, архитектуры, состав приложения и целостность DMG.
Установщик содержит только приложение и инструкцию, без пользовательских данных.

Сборки подписываются ad-hoc и не проходят notarization Apple.
Для публичных обновлений с постоянной идентичностью разработчика нужны
Developer ID, соответствующая подпись и notarization.

## Хранение и вход

- Заметки, вложения, корзина и лейблы: `~/Library/Application Support/DevNotes/notes.vault`.
- Шифрование: AES-256-GCM через CryptoKit, случайный nonce, аутентифицированный заголовок.
- Ключ: отдельная запись Keychain `local.devnotes.notes-encryption.v1`, без синхронизации iCloud.
- Запись архива атомарная, с проверкой расшифровки. Ошибка открытия не заменяет архив пустым.
- Неудачное сохранение перед выходом отменяет закрытие приложения.

Режим входа выбирается при первом запуске и изменяется в настройках:
без блокировки, только Touch ID либо системный вход с резервным паролем Mac.
Изменение режима подтверждается текущим способом входа. После разблокировки
повторный вход до завершения процесса не требуется, включая сон и переключение окон.

Блокировка интерфейса не привязывает ключ криптографически к отпечатку или Secure Enclave.
Режим без блокировки сохраняет шифрование и стандартный ACL Keychain.
После пересборки macOS может отдельно запросить разрешение доступа к ключу.
В режиме «Только Touch ID» недоступная биометрия не заменяется паролем.

Для восстановления нужен и архив, и исходный ключ: одного `notes.vault` недостаточно.
CSV/XLSX не шифруются. Названия и параметры быстрого времени напоминаний,
режим входа и ширина панели хранятся в UserDefaults без шифрования.
Уведомления содержат общую подсказку и UUID, без текста заметок.

## Формат данных

Приложение работает с `notes.vault`; импорт из незашифрованного JSON не поддерживается.
Формат шифрования и идентификатор Keychain сохранены, поэтому существующие
зашифрованные архивы открываются без переноса. Неиспользуемые служебные поля
архива игнорируются при чтении. Совместимость структуры блоков внутри архива сохранена.

## Диктовка и экспорт

Диктовка использует только локальное распознавание `ru-RU`; при его недоступности
серверного запасного режима нет. Аудиофайлы не создаются.

XLSX собирается в закрытом временном каталоге и атомарно записывается по выбранному пути.
CSV добавляет апостроф перед текстом, который табличный редактор может принять за формулу.
Ссылки открываются только для HTTP, HTTPS и электронной почты.
